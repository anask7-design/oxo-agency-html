# OXO Agency — site HTML

Version source du site vitrine actuellement testé sur `web.oxo-agency.com`.

## Structure

- `index.html` : accueil
- `site-*.html` : pages de services, blog et contact
- `oxo-site.css`, `oxo-motion.css`, `oxo-motion.js` : styles et animations
- `fonts/` : police Bebas Neue locale
- `devis.php`, `contact.php` : traitement des formulaires

Le dépôt GitHub conserve le code et l'historique. Aucun déploiement automatique vers cPanel n'est configuré à ce stade. Les envois des formulaires doivent être vérifiés sur le serveur.
